# Upstream behavior and domain register

Source: EcoLogits 0.11.1 PyPI artifact, requested commit `886d1ebfadb51a2d6407fcea6d9778c997c85c35`. Immutable hashes are in `upstream/lock.json`. Every item below is preserved or explicitly excluded; no correction is published under the source identity.

| ID | Reproducer and actual Python behavior | Port disposition |
| --- | --- | --- |
| D01 | `Model.from_json` checks `source` before reading `sources`. Ordinary records with only `sources` load an empty list. Singular `source` without `sources` raises KeyError. | Raw normalized models and `modelFromJson` preserve this. `catalog.model_provenance` retains the original links and JSON pointers independently. Tests EL22-source-loader, EL22-singular-source, EL22-singular-missing-sources. |
| D02 | `command-a-plus-05-2026` has `architecture.type='moe'`, scalar parameters 218 and sibling `active_parameters=25`. The Pydantic architecture drops the sibling; the bridge uses 218 for both counts. | Preserve the actual loader/bridge. Explicitly classify the ignored source field during conversion. Every catalog model is compared to Python. Do not infer a corrected 25B method. |
| D03 | `RangeValue` pairs corresponding endpoints for addition/multiplication, including scalar/range arithmetic. Negative scaling can reverse endpoints and raise ValidationError. | `values.ts` preserves pairing and failure. No Cartesian expansion or reordering. EL04/05 and EL16-negative-range-multiplier. |
| D04 | `__rtruediv__` aliases forward division, so `2 / RangeValue(2,4)` becomes `[1,2]`, not `[0.5,1]`. Range/range division may build nested ranges and then raise ValidationError; zero can fail earlier with ZeroDivisionError. | Preserve raw reverse division and error ordering. Product calculations accept only declared scalar divisors. EL22-reverse-division and EL05-range cases. |
| D05 | Range `<`/`>` use disjoint endpoints, while `<=`/`>=` use asymmetric endpoint tests. `BaseImpact` derives `<`/`>` from `__le__` via total_ordering, so impact comparisons differ from direct interval comparisons. | Explicit `less`/`greater` and `compareImpacts` preserve their separate source semantics. EL05-range and EL21-compare. |
| D06 | A registered alias can overwrite another alias or model name; model duplicates themselves fail. Alias targets resolve in insertion order. | Pure `createModelRepository` preserves raw behavior. Baseline converter rejects ambiguous aliases so a future catalog cannot silently alter identity. EL02 and EL22-alias-overwrite. |
| D07 | `DAG.execute` skips explicit supplied assets, even null. Dependencies still participate in graph traversal. Null required dependencies are omitted before calling the source function and fail; missing graph leaves raise KeyError. | Explicit typed graphs preserve dependency/override outcomes. All assets receive override tests. Dynamic Python annotation reflection is replaced, not shipped. EL08 and EV10 overrides; EL22 null/absent cases. |
| D08 | LLM absent/null request duration becomes infinity; duration zero caps modeled latency at zero but does not erase output-token GPU energy. TPS zero divides by zero. TTFT uses `ttft or 0`. | Preserve raw behavior and separate strict product validation. EL09/10 fixtures include omitted, null, zero, exact cap and zero TPS. |
| D09 | Video helper omitted location defaults to WOR; explicit None uses the provider location. Text omitted/null location uses the provider default. | Preserve exactly in separate lookup APIs. EV09 and EL11. No location inference from an IP. |
| D10 | Video low-level docstring says watts, but the helper divides source hardware watts by 1000 and its kernel uses kW. The video server energy is the full selected machine. | Preserve executable units/allocation. No LLM batch or GPU-fraction rule is applied. EV06/07 compare all hardware/profile combinations. |
| D11 | Video baseline includes audio. True leaves non_audio_weight at 1; false uses the stored adjustment, which is 1 for non-audio profiles. The helper does not accept a request-latency cap. | Preserve helper signature and weighting; a cap is available only in low-level video functions. EV05 and EV10-high-level-rejects-cap. |
| D12 | Video uses `int(duration * 24 + 1)`, which truncates toward zero for negative values too. Python int accepts Unicode decimal digits and surrounding Python whitespace in dimensions. | Preserve parsing and truncation for represented values. Positive safe dimensions/frames are required at product admission. EV02 Unicode/whitespace and EV03 boundary fixtures. UTF-8 transport is explicitly enabled for the oracle on Windows. |
| D13 | Negative predicted latency may produce a negative scalar result, or fail validation when multiplied into a nondegenerate power range. Nonfinite values are not consistently rejected upstream. | Preserve raw results/failures and reject impossible product outputs with `validateImpacts`. EV11 scalar/range and nonfinite fixtures. |
| D14 | Python integers can exceed binary64's exact domain. Pydantic also coerces some booleans/strings and renders detailed version-dependent validation errors. | Typed raw reference API is numeric; product schemas reject coercion, unsafe counters, invalid objects and unsafe video integer intermediates. Python exception class and high-level status text/code are compared, not traceback formatting. EL16-18. |
| D15 | BaseImpact addition checks type but does not separately validate equal units; WCF and energy are usage-only and no embodied water exists. | Preserve raw helper behavior and phases. Product result validation requires known units and retains phase boundaries. EL14 and EL21. |
| D16 | Python NaN is truthy in `ttft or 0`, whereas JavaScript NaN is false under `||`. The first port incorrectly replaced NaN TTFT with zero. | Port.2 fixes this port defect using explicit null/zero checks. F3 raw scalar/DAG cases now match Python; product validation still rejects NaN. This was not an upstream defect. |
| D17 | Python int has no signed zero, but binary64 floats do. JSON would otherwise erase input/output negative float zero; JavaScript truncation and numeric parsing can retain negative zero for integer outputs. | The oracle protocol preserves float `-0` explicitly. Integer frame/dimension conversions normalize zero as Python does. F3 and EV02/EV03 signed-zero cases compare actual Python. |
| D18 | Raw video lowering accepts zero duration as one frame, and source/Python typing does not itself establish a strict product schema. | `validateVideoLookupInput` must run before lowering. It rejects invalid durations/audio/resolutions and PUE below one without changing raw helper behavior. Low-level and output validation remain subsequent steps. |
| D19 | `electricityMixFromJson` is a typed raw helper, not the full Python float parser. Python also accepts Unicode decimal text. | Its supported text domain is explicitly ASCII numeric text. The pinned catalog lies inside this domain; arbitrary Unicode/coercible loader objects are not admitted product data. |
