# EcoLogits 0.11.2 model update

30 September 2026. The corrected upstream catalog has been adopted locally and the Chrome, Edge and Firefox extension directories rebuilt. This is local implementation and build evidence, not publication or installed-browser verification.

## Source and timing correction

The maintainer closed [issue 264](https://github.com/mlco2/ecologits/issues/264#issuecomment-5897292509) with “Fixed in 0.11.2”. The Git tag `0.11.2` resolves to `c739e8d61f6a12a85864adb698ab85623fe70f3c`. The release was published on 29 September. Downloaded GitHub and PyPI source bytes agree on the candidate Python and JSON surface. PyPI source SHA256 is `518969a1ec84d4336168645416033617bc515f061d7c13b9b9c53add9f4f0a5c`.

The new data resolves the observed timing failures without an application-side conversion:

- GPT-5.5 now has TPS 47 and TTFT 2.16 seconds, replacing the rejected catalog's TTFT 2620.75.
- Gemini 2.5 Flash Image now has absent throughput and TTFT 13.48 seconds. It uses upstream's existing regression when throughput is absent, rather than dividing by zero. This check does not enable image generation through the text estimator.
- No model in the normalized catalog has nonpositive numerical throughput. The largest supplied TTFT is 48.34 seconds, rather than the rejected catalog's millisecond-scale values.
- Relevant calculation functions, electricity factors, provider defaults and video data are unchanged. The existing TypeScript core identity remains `0.11.1-port.2`; accepted upstream version and both Python environments now use `0.11.2`.

The package metadata review found only the version change. Direct dependency constraints, transitive oracle pins, license and citation bytes are unchanged. A hash-bound review in the private stage clears that metadata change. The source-to-port map, retained source manifest, notices, coverage and attribution were generated by the existing maintenance workflow.

## Models and product mappings

Compared with the accepted 0.11.1 catalog, this release adds 25 model records, removes 30, modifies 129 and removes three aliases. The active catalog contains 339 models plus nine aliases, 215 electricity zones and 17 video models. The previous 0.11.1 source snapshot remains in the repository, and the rejected September 22 stage remains separate.

The 25 additions include the earlier 20-model candidate plus Claude Opus 5.5, Claude Sonnet 5.5, GPT-6 Luna, GPT-6 Sol and GPT-6.1 Sol. All are imported into the core library. Consumer recognition is a separate boundary: the five additional API names do not establish new website extraction mappings by themselves.

Thirteen previously recognized consumer labels now use direct upstream profiles, bringing direct bindings to 20:

| Site | Newly direct profiles |
| --- | --- |
| ChatGPT | GPT-5.6 Sol, GPT-5.6 Luna |
| Claude | Fable 5, Fable 5.1, Opus 5, Sonnet 5 |
| Gemini | 3.6 Flash |
| Perplexity | GPT-5.6 Terra and Sol, Claude Sonnet 5 and Opus 5, Gemini 3.8 and 3.7 Flash |

The six obsolete Perplexity proxy overrides were removed so they cannot mask the new direct bindings. Existing provider fallback profiles and the GPT-5.5 unknown-provider benchmark remain unchanged. GPT-6 Pro, Sol Pro, generic modes and Perplexity GLM retain their existing policies because catalog names alone do not verify an API or hosting correspondence.

The newer owner decision making EcoLogits the only selectable product engine is preserved. The archived Original method, source data and historical result handling are unchanged. This update makes no storage migration, capture changes or compact-bar changes. The method hash changes to `5e61b03c7249d0b421b28db63ff9b4483d35b0af793e550aa00a457c37251d70`, allowing existing method-change/recalculation handling to distinguish the new data while retaining originals. Archived native definitions with a different source identity remain explicitly unavailable for native recomputation, as before.

Direct mappings retain the unvalidated-reference and assumed-provider-environment disclosures. They establish name correspondence for a reference estimate, not physical calibration.

## Verification

- Candidate verification: **24,195** candidate-Python versus candidate-TypeScript cases passed, with 822 accepted-to-candidate changes including metadata and availability. Deterministic generation passed.
- Adopted core suite: **20 tests passed**, including exact corrected timing, nonpositive-throughput rejection, raw regression behavior, provenance and source-map checks.
- Estimator suite: **114 tests passed**, including newly direct models, Perplexity selections, fallback behavior and legacy characterization.
- Native server focused suite: **340 tests passed**, covering native source admission, catalog overlays, product parity, exports and estimation contracts.
- Expanded native/TypeScript product parity: **2 tests passed**, including live and historical calculations for every one of the 20 direct mappings, with exact method/profile identities and the existing numerical tolerances.
- Full workspace typecheck and Python lint passed. The clean public-source check passed offline.
- Documentation suite: **105 tests passed**. Historical worked-reference inputs remain unchanged; text edits preserve the 623 original article review anchors and generated pages agree with the authored article.
- Chrome, Edge and Firefox intermediate builds passed. Each contains the 0.11.2 lock, catalog hash, updated methodology and matching corresponding-source ZIP.
- Full extension regression suite: **1,012 passed, 1 skipped**, with zero failures. This includes the 10,050-request history aggregation case. Native browser/provider behavior, PostgreSQL and external distribution gates are separate and were not exercised by this update.

Local build directories are `apps/extension/.output/chrome-mv3`, `edge-mv3` and `firefox-mv2`. Existing downloadable release ZIPs were not republished. No installed browser profile was changed, and no server was deployed or restarted.

The dependency inventory and SBOM were regenerated. This also includes the already-used `@streamparser/json` dependency introduced by preceding history work. Unrelated popup/icon edits present before this task were preserved.

Final source review found no remaining issue in the scoped diff. Original estimator source, the pure calculation core and the previous 0.11.1 retained snapshot are byte-unchanged. Each browser's corresponding-source ZIP was opened and checked against the current catalog, identity, lock and configuration bytes, including the presence of both source snapshots. No independent reviewer or extra agent was launched.

## Reproducibility and local recovery

The private stage `.git/ecologits-model-update-2026-09-30` contains artifact hashes, the accepted baseline, metadata review, semantic report, parity evidence and test/build logs. A separate frozen oracle environment was prepared for 0.11.2 before staging. Adoption transaction `tx-6cf5526dedb9-6a8da989` retains backups under the ignored `.ecologits-maintenance/` directory. Product mappings and native adapter changes are separate reviewable source changes; the adoption rollback alone does not revert those files.

Windows initially prevented removal of stale 0.11.1 package metadata during local environment synchronization. The remaining metadata directories were moved to the private stage's `environment-backups` directory, then both environments synchronized successfully to their frozen 0.11.2 locks. Subsequent tests and the clean-source check passed.

EcoLogits-derived files remain MPL-2.0.
