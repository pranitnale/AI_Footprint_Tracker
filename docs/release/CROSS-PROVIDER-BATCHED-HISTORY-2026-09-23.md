# Cross-provider batched history import

The earlier Claude correction removed its whole-conversation cutoff, but ChatGPT, Gemini and Perplexity still used a 1 MiB response ceiling and bounded whole-page message/text totals. A separate Perplexity recorded-thread matcher stopped at 1 MiB or 100 entries. Long observed history could therefore remain unavailable even though the chat loaded in the provider.

ChatGPT and Perplexity now parse host-issued JSON responses row by row. They forward at most 50 countable messages or about 512 Ki text per acknowledged batch, except for one indivisible message. The private counting worker runs before the background retains each row's numerical result and minimal relationship metadata. At completion, ChatGPT request and parent links are resolved across batch boundaries; Perplexity's first-entry proof and dates are checked across the full observed page. Only then are numerical records committed in 100-message groups. Claude continues to use its selected-branch stream. Gemini's observed history RPC requests ten turns per page; the frame is decoded as one provider page and its countable messages are forwarded and counted in bounded batches. None of these import paths has a conversation-wide response, message or text-unit cutoff.

The Perplexity recorded-thread observer also parses response entries incrementally instead of buffering the full response. Matching a single long page now hashes and links request IDs in groups of 100, matching the local and paired-server relation contracts. An observed page of 230 recorded requests links all 230; the coverage count is not truncated to 100.

The extension still only observes history the provider itself loads. It does not fetch unseen pages, scroll private chats or infer hidden model work. Individual message text and file fields retain validation bounds; unsupported fields stay unknown. Browser XHR APIs may already hold a full response before an extension observer can read it, and Gemini's ten-turn frame must be decoded as a provider page. This is a bounded-work import, not a claim that every provider exposes every historical turn or exact billed tokens.

Synthetic checks cover ChatGPT's 1,100-message page above the former response and message thresholds, Perplexity's 600-entry page, a Gemini page above 1 MiB, provider-adapter text/completeness parity, actual private-counter and ledger commits for all three, and a Perplexity recorded membership response above 1 MiB. No raw prompt text appears in the tested saved records. Chrome, Edge and Firefox production builds and extension typechecking pass. Native installed-browser verification remains separate; activating the rebuilt extension requires a reload in the browser's extension manager and a one-time refresh of already-open provider tabs.
