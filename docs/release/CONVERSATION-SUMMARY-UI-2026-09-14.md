# Compact conversation summary verification

The extension combines earlier prompts and recorded requests under Requests. Confirmed live matches and conflicting history records are excluded from earlier contributions. Unverified overlap remains a provisional estimate with a visible Matching incomplete status. Original numeric records, source dates and calculation evidence remain separate. Compatible token and text-resource groups combine; incompatible groups and local/pending/synced snapshots do not.

Details presents statistics with expandable measurement sources. The first-message hint is independent of calculation accuracy. Methodology is available offline in each browser build, and the same authored article feeds the public website and design canvas. All 623 existing methodology review anchors remain unchanged.

- Extension TypeScript check passed.

This is local UI and build verification. It does not certify provider-native behavior or extension performance in installed Chrome, Edge and Firefox sessions. No provider prompts were sent, no production deployment was changed, and no stored observations were migrated.
