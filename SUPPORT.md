# Support

AI Footprint Tracker 0.1.0 is an unsigned, unreleased candidate. There is no production support or service-level commitment.

Use the repository issue forms for:

- reproducible software defects in a supported browser or site;
- feature and methodology proposals;
- self-host deployment questions based on the documented configuration.

Start with the [README](README.md), [self-hosting guide](docs/operations/SELF-HOSTING.md), [privacy guide](docs/privacy/README.md) and [methodology](docs/methodology/content.html). For security or privacy vulnerabilities, use the private process in [SECURITY.md](SECURITY.md).

Safe reports include the candidate version or commit, browser and operating-system version, supported site, synthetic steps, expected behavior, observed behavior and sanitized error text. State whether the extension was local-only or connected, without naming an organization.

Never post credentials, signed URLs, raw IP addresses, private hostnames, employee content, real prompts or answers, authenticated HAR files, production logs, browser profiles, real company exports or employee documents. Create a synthetic reproduction instead. The project cannot recover or inspect a private deployment for you.
